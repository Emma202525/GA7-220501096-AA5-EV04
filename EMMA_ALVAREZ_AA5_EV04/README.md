# GA7-220501096-AA5-EV04 - API del proyecto

**Aprendiz:** Emma Alvarez

## Proyecto

Sistema de inventario sencillo para tiendas o pequeños negocios.

Esta evidencia corresponde al testing mediante Postman de las API desarrolladas en GA7-220501096-AA5-EV03.

## Contenido

- `src/server.js`: API del proyecto.
- `postman_collection_GA7_AA5_EV04.json`: colección Postman con 11 pruebas.
- `PRUEBAS_API_PROYECTO.md`: documento de pruebas y espacio para pantallazos.
- `ENDPOINTS.txt`: endpoints de la API.
- `GUIA_VIDEO_POSTMAN.txt`: guion del video.
- `repositorio.txt`: enlace del repositorio.
- `API.md`: documentación de los servicios.
- `package.json`: dependencias.

## Ejecución

```bash
npm install
npm start
```

Servidor:
`http://localhost:3000`

## Pruebas

Importar la colección JSON en Postman y ejecutar las solicitudes en orden. La prueba de creación guarda automáticamente el ID del producto para utilizarlo en las solicitudes siguientes.

## Entrega

El video y los pantallazos deben ser realizados por el aprendiz durante la ejecución real de las pruebas en Postman.
